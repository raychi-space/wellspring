# Raychi v0.2 · wellspring 内容服务任务说明

本文保留早期任务范围；对应[模块 Issue #2](https://github.com/raychi-space/wellspring/issues/2)及已完成的[跨仓主 Issue #1](https://github.com/raychi-space/raychi/issues/1)。项目级产品依据见 [Raychi 产品需求 v0.2](https://github.com/raychi-space/raychi/blob/main/docs/product-v0.2.md)。后续内容已收敛为文章和帖子，并增加搜索、写作助手、发布元数据及账号持久化；当前行为以[内容契约](api/contract-v0.2.md)、[写作契约](api/writing-agent-v1.md)和 [README](../README.md)为准。下文不是当前功能进度，本仓仍拥有 HTTP 契约与数据迁移。

## 业务语义

1. 支持长文、帖子、思考三种内容。长文标题必填，可选封面；帖子和思考标题可空且不能依赖标题生成公开地址。三类正文均为 Markdown；帖子和思考不接受图片引用或图片上传。具体校验和错误码在契约中确定。
2. 长文和思考恰好属于一个分类，未选时归入默认分类；帖子没有分类。长文和帖子可关联多个标签，思考没有标签。站长能添加分类和标签；长文/思考共用分类集合，长文/帖子共用标签集合。
3. 三类内容均有工作稿与当前发布快照。暂存、发布、再次发布和撤回保留现有文章的可见性语义；访客接口只返回发布版本。撤回后公开列表/详情/回顾不可见，管理端仍可读并再次发布。未发布长文图片保持私密，现有图片权限不能退化。
4. 提供公开混合信息流、各类型列表与详情、回顾筛选所需数据，并以稳定顺序分页。仅保存工作稿不能改变公开时间线位置。无标题内容有稳定详情标识；现有 `/writing/{slug}` 链接继续可用。
5. 管理站点配置包含站名、简短介绍、头像、联系方式、外部账户、导航文字/链接和首页预设区块显示/顺序。管理保存成功后立即可被公开接口读取，不经过内容发布快照。

## 契约与迁移工作

- 先评审 OpenAPI、语义说明、成功/失败样例及三方兼容顺序，再实施迁移。明确可空标题、分类/标签约束、无标题地址、筛选与分页、配置读取/写入、认证/CSRF、冲突与撤回行为。
- 迁移保留既有长文、附件、发布快照和 URL。不要以新类型使旧文章图片变成匿名可读，或让旧客户端误读草稿。
- 对默认分类、分类/标签更名与删除、文章默认封面是否由服务端提供、再次发布排序等未定细节，在契约 PR 中提出可验收方案供产品确认。

## 模块验收

- 数据迁移后既有文章和图片权限保持；三种内容的草稿、发布、再次发布、撤回及分类/标签校验有测试覆盖。
- 公开混合列表和回顾只返回已发布快照，顺序及筛选稳定；无标题内容详情可访问；撤回后匿名读取不可见。
- 站点配置管理写入需认证与 CSRF，公开读取仅包含可公开字段；保存成功后立即可读。
- 运行 `mvn test`，并用真实 MySQL 与 HTTP 记录集成结果；H2 测试不能代替跨仓验收。
